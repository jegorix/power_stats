**1. Установка зависимостей**
Перед сборкой необходимо установить компилятор и нужные библиотеки (Qt5 и udev). Открой терминал и выполни:

```bash
sudo apt update
sudo apt install build-essential cmake qtbase5-dev libudev-dev

```

**2. Размещение файлов**
Создай папку (например, `lab_power`) и скопируй в неё файлы из `lab1`:

* `CMakeLists.txt`
* `power_monitor.cpp`
* `power_gui.cpp`
* `battery_data.h`
* `battery_data_test.cpp`

**3. Сборка проекта (Билд)**
Открой терминал прямо в этой папке (или перейди в неё через команду `cd`). Выполни команды строго по очереди:

```bash
mkdir build
cd build
cmake ..
make

```

**4. Запуск лабораторной**
После того как команда `make` дойдет до 100%, в папке `build` появятся два готовых исполняемых файла. Их нужно запустить параллельно.

В **первом** окне терминала запусти консольный демон:

```bash
./power_monitor

```

*Он напишет, что запущен, и останется висеть в фоне. Так и должно быть.*

Не закрывая первый терминал, открой **второе** окно терминала, зайди в ту же папку `build` и запусти графический интерфейс:

```bash
./power_gui

```

**5. Остановка работы**
Закрой графическое окно крестиком. Чтобы показать преподавателю, что условие задачи выполнено, обрати его внимание на первый терминал — `power_monitor` всё ещё будет работать.

Для полной остановки фонового демона перейди в первый терминал и нажми сочетание клавиш `Ctrl + C`.

Батарея определяется по `type=Battery` в `/sys/class/power_supply`, независимо от имени устройства. Отображается первая по имени батарея с доступным зарядом; батареи периферии (`scope=Device`) пропускаются. Данные перечитываются каждые 2 секунды и по событиям udev. Если `capacity` недоступен, процент рассчитывается по `energy_now/energy_full` или `charge_now/charge_full`. Если Linux не предоставляет данные батареи (например, в виртуальной машине), интерфейс показывает, что заряд недоступен.

Для запуска тестов после сборки выполни в папке `build`:

```bash
ctest --output-on-failure
```
